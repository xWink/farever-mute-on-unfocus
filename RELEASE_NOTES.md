# v1.0.0

Initial release of Farever Mute When Unfocused.

## Install

Copy `mute-unfocused.hl` to:

```text
Farever\hlx\mods\mute-unfocused\mute-unfocused.hl
```

Requires HLX Core.

## Behavior

- Alt-Tab away from Farever: game audio mutes.
- Return to Farever: previous game volume is restored.
- Does not modify the Windows volume mixer or other applications.
